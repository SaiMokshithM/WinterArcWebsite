# SAI — WINTER ARC (90 DAYS OF DISCIPLINE)

> **90 DAYS. ONE MISSION. A STRONGER YOU.**
> *“Discipline is choosing what you want most over what you want now.”*

A cinematic, luxury editorial 90-day discipline and self-improvement tracking website built with pure **HTML, CSS, and vanilla JavaScript**.

---

## ⚡ Features

* 🏔️ **Cinematic Gateway & Atmosphere:** Dark obsidian & champagne gold luxury visual architecture with ambient canvas snowfall and Web Audio API synthesized mountain wind.
* 👤 **Local Profile System:** 100% private, client-side persistence in `localStorage`.
* 📋 **12 Daily Non-Negotiables:**
  * Wake Up Early (Before 6:00 AM)
  * 7–8 Hours Sleep
  * Workout / Exercise
  * Drink 3–4 L Water
  * Healthy Diet (No Junk)
  * Study / College (3+ hrs)
  * Coding / Skill (2+ hrs)
  * Project / Portfolio Work
  * Read / Learn (Non-Syllabus)
  * Meditation / Journal
  * No Social Media (≤ 1 hr)
  * Stay Consistent
* 📊 **Progress & Streak Engine:**
  * Animated circular SVG progress gauge with celebration badge upon 100% completion.
  * Real-time streak calculator (Current Streak, Best Streak, 100% Days, Arc Average).
* 📅 **90-Day Visual Calendar & 30-Day Streak Matrix:**
  * Grouped into Phase 1 (Foundation), Phase 2 (Consistency), and Phase 3 (Standard).
  * Interactive 7-Day Weekly Matrix (Mon–Sun) directly from the reference poster.
  * 30-Day circular streak bead map.
* 🎯 **Milestones & Reviews:**
  * Monthly discipline targets & 13-week sprint planner.
  * Daily Priorities (Top 3) & Gratitude reflections.
  * Daily Journal with timeline history & Sunday weekly reviews.
* 📈 **Pure Vanilla Canvas Analytics:**
  * High-DPI interactive trend charts for 7, 30, and 90 days without any external libraries.
* 💾 **Data Sovereignty:**
  * Single-click JSON export & import backup system.
  * No external backend, no databases, works completely offline.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```powershell
Start-Process "index.html"
```

## 🛠️ Tech Stack

* **HTML5** — Semantic, accessible markup.
* **CSS3** — Custom properties, glassmorphism, responsive grid & flexbox, `@media (prefers-reduced-motion: reduce)`.
* **Vanilla JavaScript (ES6+)** — Namespaced `localStorage`, Canvas 2D particle & chart rendering, Web Audio API synthesis.
